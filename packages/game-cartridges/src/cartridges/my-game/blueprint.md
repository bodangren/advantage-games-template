# Crystal Courier Reference Blueprint

Crystal Courier is a suggested starting point, not a required genre. It demonstrates how a cartridge can turn a vocabulary decision into a short, readable game consequence while using only the organizer-owned selected palette.

- Player verb: choose the correct Thai translation to open the courier's route.
- Learning mode: vocabulary.
- Correct consequence: the courier moves, a blue crystal celebrates, and the score advances.
- Incorrect consequence: the sentinel reacts, a coin flickers, and the attempt is recorded.
- Win condition: answer every supplied prompt; the cartridge emits results exactly once.
- Controls: tap/click an answer or press `1` / `2`.
- Palette: resolve stable roles through `context.assets.resolve(...)`; do not copy paths or URLs.

Teams may replace the fiction, pacing, and mechanic. Preserve the learning loop, contract, responsive layouts, and palette rules in [COMPETITION_PALETTE.md](../../../../../docs/COMPETITION_PALETTE.md).
