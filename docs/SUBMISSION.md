# Submission

1. Complete `submission.json` without changing its schema version or source path.
2. Update `blueprint.md` with the repeated action, learning loop, controls, correct/incorrect consequences, and win condition.
3. In `definition.ts`, list the exact Crystal Courier roles your cartridge uses in `manifest.requiredAssetBindings`.
4. Show the visible credit **Pixel art assets by ElvGames** in your game or demo presentation.
5. Run `pnpm validate`.
6. Commit your allowed files and push your branch.
7. Open a pull request and include compact and wide screenshots plus concise play instructions.
8. Be ready to complete the learning loop in a three-minute live demo.

Do not submit raw asset URLs, source filenames, external art, or code that bypasses `context.assets.resolve(role)`.
